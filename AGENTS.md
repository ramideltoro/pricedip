# PriceDip maintenance

Keep substantive documentation in ramideltoro/pricedip-wiki. For behavioral, configuration, dependency, or infrastructure changes, update the corresponding guide and documentation contract before release. Never refresh fingerprints as a substitute for updating explanations. Run npm test and npm run build; run documentation synchronization validation against the exact code tree. Run browser verification for visible changes. Keep fixtures separate from live data and never weaken seller verification to populate results. Never expose account settings or credentials. Untrusted pull requests must not receive production secrets. Never automatically purchase, bid, or message sellers. No paid service fallback. Maintain all checks when changing deployment workflows.
